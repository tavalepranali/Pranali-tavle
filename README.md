# 📈 Stock Portfolio Tracker

A simple Python project that calculates the total value of a stock portfolio based on predefined stock prices and user input.

## 🚀 Features

- Uses a predefined stock price dictionary.
- Accepts stock names and quantities from the user.
- Calculates the total investment value.
- Displays portfolio summary.
- Beginner-friendly Python project.

## 🛠️ Technologies Used

- Python 3

## 📂 Project Structure

```
Stock-Portfolio-Tracker/
│── main.py
│── README.md
```

## ▶️ How to Run

1. Clone this repository.
2. Open the project folder.
3. Run the following command:

```bash
python main.py
```
